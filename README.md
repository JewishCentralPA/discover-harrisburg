# Discover Harrisburg | Family Recruitment Shabbaton

Live site: GitHub Pages (once enabled)

An all-inclusive, fully catered recruitment weekend site for families exploring Harrisburg — affordable housing, Orthodox infrastructure, career opportunities, and the Aishel Campus retreat in New Bloomfield, PA.

## Run locally
Open `index.html` in a browser, or:
```bash
python3 -m http.server 8000
```
Then visit http://localhost:8000
